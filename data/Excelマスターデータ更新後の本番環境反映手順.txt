============================================================
■ Excel マスターデータ更新後の本番環境反映手順
============================================================

【前提】
本番サイトは Excel（.xlsx）を直接読み込まず、「data/setup_data.json」を参照します。
Excel を編集・保存したあとは、必ず以下の手順で JSON 変換と GitHub プッシュを行ってください。

------------------------------------------------------------
手順 1：プロジェクトフォルダを VS Code で開く
------------------------------------------------------------
1. VS Code で「marathon-share-setup」フォルダを開く。
2. 上部メニュー「ターミナル」＞「新しいターミナル」を開く。

------------------------------------------------------------
手順 2：Excel の内容を JSON（data/setup_data.json）へ変換する
------------------------------------------------------------
ターミナルで変換用 Python スクリプトを実行します。
（※スクリプト名が不明な場合は「Get-ChildItem」で確認）

  python 変換スクリプト名.py

■ 確認ポイント：
・エラーが出ずにコマンドが完了すること。
・「git status」を実行し、「modified: data/setup_data.json」と表示されること。

------------------------------------------------------------
手順 3：GitHub へプッシュして本番環境（Vercel）へ反映する
------------------------------------------------------------
ターミナルで以下の3行を順番に実行します。

  git add .
  git commit -m "Update: sync setup_data.json from Excel"
  git push

■ 確認ポイント：
1. Vercel の「Deployments」画面で最新ビルドが緑色の「Ready」になるのを待つ（約1〜2分）。
2. 本番サイト（https://marathon-share-class-setup.vercel.app）を開き、
   スーパーリロード（Ctrl + Shift + R）を押して Excel の変更内容が反映されているか確認する。
